# Dois Amores Doceria — V3.0

Evolução visual e de experiência construída sobre a V2.4.

## Principais melhorias
- Identidade visual mais premium e contemporânea.
- Header translúcido com navegação horizontal no mobile.
- Hero com hierarquia, contraste e CTA mais fortes.
- Cards de produtos com imagens maiores e tratamento editorial.
- Estados hover, foco e interação mais consistentes.
- Banner de pedido coletivo e seções institucionais refinados.
- Carrinho com aparência de drawer premium, mantendo a lógica existente.
- Modais e formulários com acabamento visual padronizado.
- Dashboard administrativo com estética de SaaS moderno.
- Responsividade para desktop, tablet e celular.
- `prefers-reduced-motion` e `:focus-visible` para acessibilidade.

## Preservado
- IDs e handlers existentes do HTML.
- Funções JavaScript e regras de negócio.
- Estrutura Supabase da V2.4.
- Produtos, estoque, pedidos, coletivos, cupons e checkout.
- Arquivos JS modulares da V2.4.
